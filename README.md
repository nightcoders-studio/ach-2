# KeudeKu – F&B Management Platform for UMKM

## 📖 Overview
KeudeKu is a modern, Acehnese‑inspired SaaS solution that turns a simple QR menu into a full‑stack **F&B management ecosystem**. It empowers Indonesian cafes, coffee shops, restaurants, and food stalls to operate like large chains—digital ordering, POS, loyalty, AI recommendations, and real‑time analytics—all in one clean, professional interface.

---

## ✨ Core Features
- **Smart QR Table Menu** – table‑specific QR codes, digital menu browsing, search & add‑to‑cart.
- **POS & Payments** – cash, QRIS, e‑wallet, split bills, receipt generation.
- **Customer Management** – profiles, order history, loyalty points, segmentation.
- **AI Recommendation Engine** – personalized menu suggestions, upselling & cross‑selling.
- **Analytics Dashboard** – revenue overview, sales trends, retention metrics.
- **Feedback Management** – ratings, reviews, satisfaction analytics.
- **User & Role Management** – Super Admin, Business Owner, Cashier, Staff, Customer.

## 🛠️ Technology Stack
- **Frontend:** Next.js 15, React 19, TypeScript, TailwindCSS (Shadcn UI)
- **Backend:** Supabase (Auth + Postgres + Serverless Functions) – optional NestJS for future extensions
- **Hosting & CI/CD:** Vercel (frontend) + Supabase hosting, Docker, GitHub Actions

## 🚀 Getting Started
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up Supabase project and configure env variables.
4. Run locally:
   ```bash
   npm run dev
   ```
5. Deploy to Vercel (frontend) and Supabase (backend).
